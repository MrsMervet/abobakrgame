# مغامرة الصياد الذكي — النسخة Premium

لعبة تعليمية تفاعلية للأطفال عن **سيرة أبي بكر الصديق رضي الله عنه**.

**إعداد المعلمة: ميرفت أمين**

## ما الذي تم تطويره؟
- واجهة افتتاحية احترافية بحركات ناعمة وهوية بصرية موحدة.
- مشهد لعب متعدد الطبقات مع سحب وجبال وكثبان وزخارف عربية.
- مسدس/قاذف كرتوني خيالي مع مؤشر تصويب متحرك وتأثير إطلاق.
- أهداف عائمة تتحرك باستمرار داخل الساحة.
- مؤثرات نجوم وجزيئات عند الإصابة.
- مؤثرات صوتية مبرمجة مباشرة عبر Web Audio دون ملفات صوت خارجية.
- نظام نقاط متقدم وتتابع Combo ومكافآت إضافية.
- حساب الدقة وعدد المحاولات وأفضل تتابع.
- شاشة نتيجة نهائية مع ميدالية وكونفيتي وتقييم تحفيزي.
- زر للصوت وزر ملء الشاشة.
- دعم الكمبيوتر والتابلت والجوال.
- واجهة عربية RTL وخطوط عربية جميلة عند توفر الإنترنت، مع بدائل محلية تلقائية.

## التشغيل
افتح `index.html` مباشرة في Chrome أو Edge.

لأفضل تجربة، يمكن تشغيل المشروع عبر خادم محلي بسيط أو رفعه إلى GitHub Pages / Netlify / Cloudflare Pages.

## بنية المشروع
- `index.html`
- `css/game.css`
- `js/game.js`
- `assets/logo.svg`

## الأسئلة
تحتوي اللعبة على 10 أسئلة مباشرة مبنية على الصفحات المرفقة عن:
الاسم، الكنية، لقب الصديق، القبيلة، المهنة، الهجرة، غار ثور، عتق بلال، الخلافة، وموقفه من المرتدين ومانعي الزكاة.
